# Fluentra v0.1.0 Pre-Release Checklist & Operator Runbook

**Stage 7 Operational Guide**  
*This document outlines the human operator steps required to validate, soak, and deploy Fluentra `v0.1.0` to production.*

---

## 1. Pre-Deployment Staging Verification

1. **Deploy to Staging Environment**:

   ```bash
   make dev-down
   make prod-up
   ```

2. **Apply Database Migrations**:

   ```bash
   go run ./cmd/migrate up
   ```

3. **Run Staging Smoke & Contract Tests**:

   ```bash
   make test-contract
   cd web && pnpm run test:e2e
   ```

4. **Headers & TLS Verification**:
   - Verify that staging achieves Grade A on security headers check (e.g. `securityheaders.com` or curl test):

     ```bash
     curl -I https://staging.fluentra.com/
     ```

   - Ensure `Strict-Transport-Security`, `Content-Security-Policy`, `X-Content-Type-Options`, and `X-Frame-Options` are returned.

---

## 2. Staging Soak & Rollback Drill

1. **24-Hour Soak Period**:
   - Run staging under synthetic traffic generator for 24 hours.
   - Monitor Prometheus alerts, error rates (5xx < 0.05%), and memory usage.
2. **Rollback Drill**:
   - Test deploying a mock patch and rolling back to `v0.1.0`:

     ```bash
     docker compose -f deploy/compose/compose.prod.yaml down
     docker compose -f deploy/compose/compose.prod.yaml up -d
     ```

3. **Database Restore Drill (1-Hour RTO)**:
   - Perform a test backup restore using the PostgreSQL dump/restore runbook and record completion time.

---

## 3. Production Deployment & Tagging

1. **Tag Release**:

   ```bash
   git tag -a v0.1.0 -m "Release v0.1.0: Phase 1 Baseline"
   git push origin v0.1.0
   ```

2. **Production Deploy**:
   - Trigger production deployment pipeline with human sign-off.
3. **Post-Deployment Smoke Verification**:
   - Verify health endpoints: `https://app.fluentra.com/health` returns `200 OK`.
   - Verify API health: `https://app.fluentra.com/api/v1/health` returns `200 OK`.
   - Execute one end-to-end user registration and verification in production.
