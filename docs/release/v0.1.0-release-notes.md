# Fluentra v0.1.0 Release Notes

**Release:** `v0.1.0` (Phase 1 Baseline)  
**Date:** August 2026  
**Status:** Ready for Staging Soak & Production Deployment  

---

## Overview

Fluentra `v0.1.0` delivers the complete Phase 1 foundational platform: a robust, modular backend monolith coupled with a modern, responsive single-page web application. The release establishes core identity, multi-factor authentication with email OTP, Google OAuth 2.0 integration, account management with direct-to-storage avatar uploads, GDPR data export/deletion workflows, administrative controls, and security hardening.

---

## Key Features & Highlights

### 1. Authentication & Security
- **Email & Password Authentication**: Argon2id password hashing with proactive breach checks (HIBP k-anonymity) and strict password policy.
- **Challenge Subsystem (OTP)**: 6-digit one-time passcodes with rate limiting (per-IP global cap + per-challenge attempt bounds), constant-time verification, and automatic challenge burning after 5 incorrect attempts.
- **Google OAuth 2.0 Integration**: Sign-in, account creation, and manual linking/unlinking with safeguards against removing the last available authentication method.
- **Session Management**: Dual-token authentication with in-memory access tokens, single-flight refresh rotation, and persistent trusted device support ("Stay signed in").

### 2. Learner Account & GDPR Controls
- **Profile & Preferences**: Customizable display name, locale, timezone, study goals, UI theme (light/dark/system), and notification channels.
- **Direct-to-Storage Avatar Upload**: Secure, presigned intent uploads directly to object storage without proxying file bytes through backend servers.
- **GDPR Article 20 (Data Portability)**: Asynchronous personal archive export with download expiration.
- **GDPR Article 17 (Right to Erasure)**: Account deletion with a 30-day grace period, immediate session revocation, and self-service cancellation option.

### 3. Administrative Management
- **Learner Search & Moderation**: Real-time learner search with cursor pagination, audited detail inspection (`admin.user_viewed`), account suspension, reinstatement, and session revocation (requiring minimum 10-character audit justifications).
- **Feature Flags**: Dynamic rollout controls with percentage bucketing, ownership assignment, and mandatory future expiration dates.

### 4. Responsive & Mobile Baseline (ADR-0024)
- **Mobile-First UX**: 44×44 CSS px touch targets, minimum 16 px input font size to prevent iOS Safari auto-zoom, and visual viewport adaptation for on-screen virtual keyboards.
- **Code Splitting & Bundle Budget**: Initial gzipped web bundle strictly constrained under 166 kB (within the 200 kB budget).
